Research Methodology & Verification Protocols

Rigorous empirical evaluation principles for Next Day Wildfire Spread (NDWS) Project 17.
Predicting Active Spread Transitions
Our Phase 1 tabular baseline explicitly models the transition from unburned to burning state (PrevFireMask = 0 → FireMask = 1). Under extreme class imbalance (0.58% to 0.96% positive prevalence), traditional ROC-AUC is misleading because 99.4% true negatives mask thousands of false alarms. Average Precision (PR-AUC) is the essential metric for honest wildfire evaluation.
Strict Partition & Scaler Isolation
To eliminate data leakage, preprocessors and scalers were fitted exclusively on training shards (train_00..13). The operating decision threshold (τ* = 0.028115) was optimized strictly on internal validation holdouts (train_14). Official evaluation shard eval_00 was scored zero-touch without tuning.
Dataset Terrain Autocorrelation Audit
An independent terrain-fingerprinting audit on the public Kaggle NDWS release revealed that 94.7% of official evaluation patches and 95.1% of test patches share identical 8×8 km SRTM elevation tiles with training data. Models on the official partition achieve 0.26 PR-AUC by memorizing local terrain; performance drops to 0.138 on location-disjoint spatial splits.
Phase 2: Spatial Deep Learning (U-Net)
While LightGBM establishes a superior tabular baseline (+77.8% AP over linear models), 1D tabular point features cannot represent 2D perimeter curvature, spotting jumps, or contiguous fuel barriers. Phase 2 transitions to U-Net convolutional encoder-decoder architectures processing full 64×64 multi-channel spatial rasters.
