# SYNTHETIC BASELINE EXPERIMENT REPORT: Candidate Line Breach Intelligence (CLBI)

> **Evidence boundary:** `data/final/fireline_segments_v1.parquet` is generated by
> `src/data/build_dataset.py`. The rows and labels are synthetic; incident names and IDs
> are profile metadata, not evidence that these records were observed during real fires.
> This report measures model behavior against a hand-authored synthetic target formula.
> It does not establish real-world predictive performance, causal effects, or operational
> readiness.

**Experiment Version:** `fireline_segments_v1_baseline`  
**Date:** 2026-09-29  
**Model Architecture:** Standardized Logistic Regression Pipeline (`StandardScaler` + `LogisticRegression`)  
**Primary Target:** `label` (1 = Held, 0 = Burned Over)  

---

## 1. Executive Summary & Core Research Question

> **Core Research Question:** *Does predicted next-day wildfire spread provide useful directional information for identifying vulnerable segments of a proposed containment line?*

### **Interpretation:** Synthetic feature-set comparison only

Adding directional features (`attack_angle`, `attack_dot_product`, `burn_prob`, `prob_gradient`, `dist_pred_boundary`) to the static feature set yields higher scores against the generated labels on the held-out CZU-named profile:

- **Static Baseline (Exp A):** PR-AUC = **0.9174** | ROC-AUC = **0.8247**
- **Full Directional Model (Exp C):** PR-AUC = **0.9526** | ROC-AUC = **0.9002**
- **Absolute Gain:** **+0.0352 PR-AUC** | **+0.0755 ROC-AUC**

These differences are descriptive results on synthetic rows. No statistical significance
or generalization to actual wildfire incidents is established.

## 4. Feature and Target Construction Audit

This table records model inputs, not an observational-data leakage audit. The generator
creates predictors and then constructs `label` from a breach-score formula using
`attack_dot_product`, `slope`, `burn_prob`, `barrier_width_m`, `distance_to_fire`, and
random noise. Consequently, this evaluation measures recovery of that generated
relationship.

| Feature Name | Status | Generated feature definition |
| :--- | :--- | :--- |
| `slope` | **INPUT** | Generated from a configured Gaussian profile distribution. |
| `elevation` | **INPUT** | Generated from a configured Gaussian profile distribution. |
| `distance_to_fire` | **INPUT** | Generated from a bounded exponential distribution. |
| `barrier_width_m` | **INPUT** | Selected from fixed synthetic line-type widths. |
| `burn_prob` | **INPUT** | Generated from a formula using distance, slope, and attack alignment. |
| `prob_gradient` | **INPUT** | Derived from generated `burn_prob` and random noise. |
| `attack_angle` | **INPUT** | Derived from generated line and spread directions. |
| `attack_dot_product` | **INPUT** | Cosine of the generated attack angle. |
| `dist_pred_boundary` | **INPUT** | Derived from generated distance and `burn_prob`. |
| `label` | **TARGET** | Synthetic thresholded score (1 = generated Held, 0 = generated Burned Over). |
| `outcome_str` | **EXCLUDE** | String representation of the synthetic target. |

## 5. Model Architecture & Experimental Protocol

- **Classifier:** `sklearn.linear_model.LogisticRegression(max_iter=1000, random_state=42)`
- **Preprocessing:** `sklearn.preprocessing.StandardScaler` inside `sklearn.pipeline.Pipeline`
- **Training Strategy:** Fit on 3,050 generated training segments. The validation (810) and test (740) sets are generated profiles. The CZU-named profile is not a real incident holdout.

## 7. Key Findings & Synthetic-Rule Interpretation

1. **Directional Geometry vs. Scalar Burn Intensity:**
   - Adding `burn_prob` alone (Exp B) increases PR-AUC from **0.9174** to **0.9381**.
   - Incorporating the geometric alignment (`attack_angle` and `attack_dot_product`) further boosts performance to **0.9526**.
   - Interpretation: the generated target formula assigns breach score directly from attack alignment and other selected predictors. Performance gains are expected when a model recovers those encoded relationships; this is not a validated physical finding.

2. **Feature Coefficient Analysis (Exp C Standardized Log-Odds):**
   - These coefficients describe associations learned against the constructed labels, not causal or physical effects.
   - **`attack_dot_product` (-1.247):** Strongest listed association with the generated `Held` target.
   - **`slope` (-0.719):** Association learned from the synthetic target-generation process.
   - **`barrier_width_m` (+0.757):** Association learned from the synthetic target-generation process.

## 9. Limitations & Next Steps

1. **Linear Model Assumption:** Logistic Regression assumes linear log-odds relationships. Non-linear interactions between slope and attack angle are not captured.
2. **Tabular Spatial Independence:** Segments are evaluated independently without spatial message-passing along neighboring 100m polyline nodes.
3. **Next Steps:** Proceed to benchmark non-linear tabular models (e.g. Random Forest / LightGBM) or Spatial Graph Neural Networks (GAT / GCN) to model spatial contiguity.
