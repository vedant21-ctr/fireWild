# Dual-target test results: spatial U-Net vs tabular models

Generated by `python -m src.dl.evaluate`. Do not edit by hand.

- **active**: next-day active fire, FireMask(t+1) on every known pixel (includes fire persistence).
- **transition**: new fire, FireMask(t+1) on pixels known not burning at day t (persistence excluded).
- **Patch-centre prior** uses pixel position only; **U-Net, full patches** can learn position. Both measure the NDWS patch-centring leak and are not valid forecasters. The primary spatial model is **U-Net, 32x32 crops**.

PR-AUC 95% CIs: patch-level bootstrap (500 resamples). Lift = PR-AUC / positive rate. All models were trained on the active target; thresholds are not used here.
